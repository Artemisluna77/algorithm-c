# 《2027数据结构》代码整理与 CLion 测试

## 目标与边界

将《2027数据结构_高清带书签版》中的代码片段按章节整理为 C17 源码，并为每个算法提供可在 CLion 中运行的测试。全书扫描范围为 404 页、8 个章节。

收录正文、题干或选项中的完整程序片段，以及答案与解析中已有的代码。孤立标识符、单个符号和数学公式不作为代码块。题目只要求编写算法但没有印出代码时，不额外补写答案。

## 实施约定

- 按章节建目录，章内区分正文、试题、答案与解析；为每个代码片段建立可追溯索引。
- 每段代码前写中文功能注释，并记录章节/小节、PDF 页码和书内印刷页码。
- 把书中的 C 写法和伪代码统一转换为可编译、可测试的 C17，保留算法意图；取地址符 `&` 和指针在 C17 中直接使用。为不完整片段补足最小编译上下文，不把题目选项改写成未印出的标准答案，不另存伪代码版本。
- 使用 CMake/CTest 和 C 标准库，不引入第三方测试框架。每个算法都配有常规与边界用例；整个项目可从 CLion 构建并运行测试。
- PDF 正文是扫描页面：对 404 页执行全页 OCR 以定位代码候选，并对候选代码页进行视觉核对；按用户决策，无需人工逐页复核 OCR 文本或目检非候选页。覆盖验收以候选页视觉核对及索引交叉检查为准。

## 全局验收

- 每个纳入范围的代码片段均能在索引中找到对应章节、类别、源页码和源文件。
- 每个算法均有测试；全部 CMake 目标可构建，CTest 中的测试全部通过。
- 正文、试题、答案解析分类清楚；每个代码片段上方有功能注释。
